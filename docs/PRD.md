# Product Requirements Document (PRD)
## GCP Multi-Agent Marketing Platform

---

## 1. Executive Summary & Vision
The **GCP Multi-Agent Marketing Platform** is an enterprise-grade AI solution designed to automate data analytics, strategy formulation, and creative copywriting for modern marketing teams. By combining **Google Agent Development Kit (ADK)**, **Agent-to-Agent (A2A) Protocol**, **Model Armor**, and **Google BigQuery**, the platform provides actionable insights and campaign generation through autonomous, specialized subagents while guaranteeing strict enterprise safety guardrails.

---

## 2. Target User Personas

| Persona | Role | Key Objectives | Primary Platform Interactivity |
| :--- | :--- | :--- | :--- |
| **Chief Marketing Officer (CMO)** | Strategic Executive | High-level ROI projections, cohort analysis, enterprise campaign alignment | Full Campaign strategy generation, high-level dashboards |
| **Data Analyst** | Business Intelligence | Querying customer segment statistics, RFM distribution, raw BigQuery SQL inspection | Data-only queries, SQL accordion inspection, table sampling |

## 3. Core Functional Requirements

### 3.1 Selective Intent-Based Workflow Routing
- The platform MUST automatically classify user prompts into three distinct execution paths:
  1. `ANALYTICS_ONLY`: Invokes `AnalyticsAgent` ONLY. Returns cohort metric summaries and executed SQL. Suppresses strategy and content cards.
  2. `STRATEGY_ONLY`: Invokes `AnalyticsAgent` -> `StrategyAgent`. Returns data analytics + campaign strategy framework. Suppresses content copy cards.
  3. `FULL_CAMPAIGN`: Invokes `AnalyticsAgent` -> `StrategyAgent` -> `ContentAgent`. Returns full end-to-end campaign deliverable.

### 3.2 BigQuery Customer Data Integration
- **Default Dataset Target**: Standard option initialized to `All Cohorts (Full Dataset)` for dataset-wide queries.
- **Live Cohort Sizing**: Total Cohort Size KPI metric MUST reflect live BigQuery dataset row counts (200 aligned records).
- **Collapsible SQL Query Inspection**: SQL queries generated by the analytics engine MUST render inside a left-aligned `<details><summary>` collapsible accordion (`🔍 View Executed BigQuery SQL Query`).

### 3.3 Security & Guardrail Infrastructure
- **Model Armor Prompt Inspection**: Every incoming prompt MUST undergo real-time validation for prompt injection, jailbreak attempts, and system prompt override attacks before subagent execution.

### 3.4 Skill & Agent Registry Store
- **Production Skill Filtering**: Internal CLI/developer skills (`google-agents-cli-*`) MUST be filtered out of the web interface skill registry to present a clean, domain-focused experience.

### 3.5 Aesthetic & Theme Standards
- **Theme Default**: System MUST initialize in **Light Mode** by default (`data-theme="light"`), with an accessible Dark Mode toggle switch.
- **UI Card Visibility**: Response cards for Strategy and Content assets MUST strictly hide when payload dictionaries are empty (`Object.keys(...).length > 0`).

## 4. Non-Functional Requirements (NFRs)

| Category | Requirement | Target Metric / Standard |
| :--- | :--- | :--- |
| **Performance** | End-to-end response latency | `< 3.5s` for `ANALYTICS_ONLY`, `< 7.0s` for `FULL_CAMPAIGN` |
| **Scalability** | Cloud Run backend concurrency | Auto-scaling `0..10` instances via GCP Cloud Run |
| **Reliability** | BigQuery Data Seeder | Batch load with `WRITE_TRUNCATE` eliminating streaming buffer lockouts |
| **Accessibility** | UI Color Contrast & Typography | Compliant with WCAG 2.1 AA standards; JetBrains Mono for code blocks |
